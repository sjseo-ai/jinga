# T007 — 경쟁 제품·가격·기능 벤치마킹

검증일 **2026-11-19** · 모든 금액은 그날 공식 페이지에서 직접 읽은 값입니다.
**확인된 사실**과 **확인하지 못한 것**을 섞지 않았습니다. 2차 출처(기사·블로그·AI 요약)에서 본 숫자는 쓰지 않았습니다.

## 0. 조사하며 알게 된 가장 중요한 것

**국내 경쟁사 세 곳은 가격을 웹에 공개하지 않습니다.** 리치고·부동산지인·아실 모두 요금이 앱 안쪽이거나
로그인 뒤에 있습니다. 공개 가격이 있는 곳은 마이랜드(국내)와 HouseCanary(미국)뿐이었습니다.

이것이 가격 전략에 주는 함의가 두 가지입니다.

1. **비교 기준점이 없습니다.** 고객은 「리치고는 얼마인데 진가는 얼마」라고 견주지 못합니다. 대신 눈에 보이는
   무료 서비스(아실·네이버 부동산)와 비교합니다. 경쟁 상대는 유료 경쟁사가 아니라 **무료 대안**입니다.
2. **이전 컨설팅 보고서가 인용한 국내 가격 수치(리치고 월 20만원 API 등)는 이번에 확인하지 못했습니다.**
   그 숫자를 근거로 가격을 정하면 안 됩니다.

**데이터 출처를 전면에 내겁니다** — 「공공데이터 기반 AI 부동산 분석 · 7종+ 공공데이터 연동」,

**민간 시세는 쓴다고 적혀 있지 않습니다.** 진가가 가려는 길을 이미 간 곳입니다.

> 주의: 같은 페이지에서 구독 카드는 「무제한 AI 분석」이라 적고 표는 횟수 제한을 적어 서로 맞지 않습니다.

## 2. 확인하지 못한 것 (가격 비공개)

| 서비스 | 시도한 URL | 결과 |
|---|---|---|
| 리치고 | `expert.richgo.ai`, `m.richgo.ai`, Play/App Store | 웹은 클라이언트 렌더링이라 본문이 안 읽힘 · 스토어 URL 404 · **요금·구독·API 표기 없음** |
| 부동산지인 | `aptgin.com/pre/main`, `/pre/payment` | 로그인 화면만. 「유료 결제를 하여야 사용 가능합니다 · 60개 이상의 부동산 분석 페이지」 **금액 없음** |
| 아실 | `asil.kr` | EUC-KR 인코딩으로 본문 판독 실패 · 중개사 홈 페이지는 빈 응답 · **요금 페이지 식별 못 함** |

세 곳 모두 **금액을 모른다**가 현재 상태입니다. 필요하면 대표가 앱에서 직접 확인하는 것이 가장 빠릅니다
(리치고 앱 → 프리미엄, 지인 → 로그인 후 결제, 아실 → 중개사 메뉴).

## 3. 기능별 무료 대체 가능성

| 진가가 주려는 것 | 무료로 이미 되는 곳 | 유료로 받을 수 있나 |
|---|---|---|
| 실거래가 조회 | 네이버 부동산 · 아실 · 호갱노노 · 국토부 | **불가** — 무료가 너무 좋습니다 |
| 단지 기본정보(세대수·주차·준공) | K-apt · 네이버 | 불가 |
| 지역 시세 흐름 | 아실 · 부동산지인(일부) | 불가 |
| 예산 조건으로 후보 좁히기 | 네이버 필터(거칠음) | **가능성 있음** — 조건이 복잡할수록 |
| 후보 3곳을 **같은 기준으로 비교** | 없음(직접 해야 함) | **가능성 높음** |
| 대출·보유비용·시나리오까지 합친 총액 | 계산기는 많으나 단지와 연결 안 됨 | **가능성 높음** |
| 「왜 A가 B보다 나은가」의 근거 | 없음 | **가능성 높음** |
| 고객에게 보여 줄 보고서 PDF | 없음 | **중개사 대상 가능성 높음** |

## 4. 여기서 나오는 가격 가설 (검증 전 가설입니다)

- 마이랜드가 **월 9,900원에 PDF 3건**을 팝니다. 자동 생성 보고서의 시장가는 **건당 3천원대**로 보아야 합니다.
- 따라서 **자동 생성 PDF 1건을 49,000원에 파는 것은 근거가 약합니다.** 사람이 검수한 심화 보고서여야 합니다.
- HouseCanary 구조를 따르면 **중개사 월 구독(보고서 생성권)**이 개인 건당 판매보다 반복성이 큽니다.
- 다만 **이 모두가 가설입니다.** T006 인터뷰로 지불의향을 확인하기 전에는 가격을 확정하지 않습니다.
