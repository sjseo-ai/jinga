## 2. 남겨 둔 것과 이유

- **구독자 주간 보고서** — 계속 보냅니다(2026-11-19 대표 지시). 보고서를 만드는 데 필요한 **구독 조건 자치구 조회만**
  남기고, 지도용 서울 전수 조회는 끊었습니다. 받는 사람이 있는 조회와 쌓아 두는 조회를 가른 것입니다.
- **이용자 검색·추천** — 이용자의 브라우저가 자기 화면을 그리려고 조회하고, 결과는 그 사람 브라우저에만 24시간 남습니다. 대표 판단으로 유지(2026-11-19).
- **시장 흐름의 집계 통계 조회** — 단지별이 아닌 지수, 저장 없음. T004 질의에 포함.
- **블로그 연재의 평당가** — 대표 판단으로 유지. 회차 준비 때만 갱신.
- **기존 Blob 조각·수집 파일** — **지우지 않았습니다.** 증거보존과 삭제정책은 변호사 확인 뒤에 정합니다(T003 지시사항).

```bash
npm test                      # 228건 (227 통과 · 1 건너뜀: 네트워크 LIVE)
```

새로 넣은 테스트 두 가지가 **기능이 조용히 되살아나는 것**을 막습니다.
- 자치구 페이지는 **시세를 넘겨도** 그리지 않습니다 — 부르는 쪽만 고치면 예전 호출 하나로 되살아납니다.
- 크론은 스위치가 꺼져 있으면 작업 파일조차 만들지 않고, **왜 안 돌았는지(`blocked`)를 남깁니다** — 조용히 넘어가면 고장과 구분되지 않습니다.

### 대체 가능성 — 재서 확인했습니다 (서울 K-apt 1,069곳 기준)

국토교통부 K-apt(`kapt-seoul.json`, **이용허락 제한 없음** · 2026-11-23 확인)에 이미 들어 있습니다.

| 항목 | K-apt 채움 | 판단 |
|---|---|---|
| 주차(지상+지하) | **99.6%** | **즉시 대체 가능** |
| 지하철 도보시간 | **96.4%** | 대체 가능 — 구간값(5분이내 … 20분초과) |

KB 가 직선거리(m)를 주던 것을 K-apt 는 도보시간 구간으로 줍니다. **정밀도는 낮지만 공식 자료이고
도보 기준이라 오히려 솔직합니다** — 지금 쓰는 직선거리는 실제 걷는 거리가 아닙니다.

보완용 공공데이터(둘 다 포털 「이용허락범위 제한 없음」 표기 확인):

- 학원·교습소 정보 `15096277` 또는 시도교육청 표준데이터 — 학원 수

### 손대지 않은 이유

이 파일들을 `jinga-reco.mjs`(매물 추천의 역세권·학군 점수)·`index.html`·`api/_job.mjs`(주간 보고서)가 씁니다.

- **재생성 중 알게 된 것(2026-11-25)**: 경사 생성기를 7분 돌리고 세션이 끊겨 **결과가 하나도 남지 않았습니다.**

  고쳤고, 다시 돌리면 받은 곳은 건너뛰고 이어서 돕니다. 경기 경사 작업 로그에 중간 저장이 7번 찍혀
  고친 것이 실제로 도는 것을 확인했습니다. 오래 도는 수집기는 **끊길 것을 전제로** 써야 합니다.

  지어낸 값이 아니라 **기존 곡선에서 유도**했습니다 — 구간 중앙값 × 분당 70m ÷ 보행 우회계수 1.4 로
  직선거리로 되돌려 기존 식에 넣은 값입니다(15 · 13.4 · 8.0 · 2.7 · 0). 기준이 아니라 정밀도가 바뀐 것입니다.
  경사 감점·길상권 가산은 역 좌표가 없어 **지금 비어 있습니다**(서울 1,069곳 역세권 평균 11.19/15).

  학교에 만점의 70% 를 주고, 학원 수는 대체 원천이 없어 일괄 2.5점입니다 —
  **이 성분은 지금 단지를 가르지 못합니다.** 화면 설명(`RECO_RULES`)에 그대로 적었습니다.

### 구멍을 막은 방식

`smoke-no-unlicensed.mjs` 를 6건 → 12건으로 늘렸습니다. 핵심은 **금지 목록을 늘린 게 아니라
허용을 증명하게 바꾼 것**입니다.

- 공개 `*.json` 에 KB 출처 표기(`KB부동산|kbland|KB시세|꿀세권`)가 있으면 실패 — 가격이든 아니든.
  (일부러 위반 파일을 넣어 **실제로 걸리는지 확인**했습니다.)
- 대장의 원천마다 어떤 공개 파일로 나가는지 적게 하고(`publicPrefixes`),
  **원자료 배포는 `redistribute === true`**, **집계·파생값 배포는 `derive === true` + 무엇을 뺐는지(`derivedNote`)** 를
  요구합니다. `null`(모른다)은 「된다」로 치지 않습니다.
- 그래서 `station-*.json`·`complex-coords-*.json` 은 **만들어도 이용허락을 적기 전까지 테스트가 빨갛습니다** —
  다음에 같은 실수를 하려 하면 배포 전에 막힙니다.
- 교체로 뺀 8개 파일이 되살아나면 실패합니다. KB 꿀세권 수집기(`npm run kb:infra`)는 실행 자체를 막고
  대체 명령을 안내합니다.
