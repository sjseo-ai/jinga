## ㉯ T011 출처 추적 가능한 보고서 — 2026-11-25

계획서 합격 기준은 **「최종 보고서에 출처 없는, 기계가 지어낸 주장이 없다」** 입니다.
「출처를 잘 달자」는 다짐으로는 못 지키므로 **구조를 바꿨습니다.**

| 지키는 방식 | 어떻게 |
|---|---|
| 출처 없는 주장을 **만들 수 없게** | `claim()` 이 출처가 없으면 던집니다. 보고서에 자유 문장 칸이 없습니다 |
| 숫자를 말로 몰래 넣지 못하게 | 주장의 글에 든 숫자는 그 주장의 `value` 에서 나온 것이어야 합니다 |
| 성격을 섞지 못하게 | 공공 신고값·법계산·추정·가정 넷으로 갈라 적습니다. 추정은 기준일, 가정은 「가정」 표기가 필수 |
| 빈칸을 메우지 못하게 | 못 채우는 칸은 `PENDING` 에 **왜 못 채우는지**와 함께 남깁니다 |

실제 단지(은마 전용 77㎡) 보고서: **주장 50줄 · 출처 20종 · 출처 없는 주장 0건**
(공공 신고값 13 · 법계산 19 · 추정 4 · 가정 14). `npm run report -- 은마` 로 눈으로 볼 수 있습니다.

**만들면서 제 구멍 셋을 검사가 잡았습니다** — 어느 것도 사람이 눈으로 찾은 게 아닙니다.
1. 시나리오 제목에 성장률(−2%)을 적었는데 매도가 `value` 에서 나올 수 없는 숫자였습니다 → 변동률을 별도 주장으로 분리.
2. 역 이름에 노선명(「3호선」)이 섞여 들어갔습니다 → 역명·노선 수를 각각의 주장으로.
3. **「출처 미기재」가 출처로 통과했습니다** — 규칙집의 법무·등기 실비에 `sources` 가 비어 있어
   「법무·등기 실비 — 출처 미기재」라는 글자가 출처 자리에 들어갔고, 비어 있지 않으니 검사를 지나갔습니다.
   **빈칸을 「없음」으로 채우면 검사를 속일 수 있었습니다.** 이제 그런 값은 출처 없음으로 보고,
   출처 없는 규칙의 금액은 「법·규칙 계산」이 아니라 **「가정」** 으로 내려갑니다.

아직 못 채우는 칸 4개 — 현장 체크리스트(인터뷰 필요) · 학원가(공공 원천 미연결) · PDF 조판(㉮ T017) · 사람 검수(㉮ T018).
