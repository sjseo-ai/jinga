# T014 — 위협 모델

작성 2026-11-20 · 구성 현황은 `docs/current-state.md` · 개인정보 점검은 `security/privacy-checklist.md`

운영자는 **한 사람**이고, 결제는 **아직 없습니다**. 그 두 가지가 아래 판단의 전제입니다.

## 1. 지켜야 하는 것 (잃으면 무엇이 곤란한가)

| 자산 | 잃으면 | 등급 |
|---|---|---|
| 구독자 메일 주소·조건 | 남의 개인정보 유출 — 되돌릴 수 없음 | **높음** |
| 임장 동행 연락처 | 같음. 연락처는 원문 저장이라 더 직접적 | **높음** |
| 관리 키·메일 계정 비밀번호 | 우리 계정에서 스팸 발송 → 발신 평판·계정 정지 | **높음** |
| 공공데이터 인증키 | 남이 우리 할당량을 씀 · 포털 계정 제재 | 중간 |
| 사이트 내용(2,000장) | 다시 만들 수 있음 | 낮음 |
| 커뮤니티 글 | 쓴 사람의 저작물 — 날리면 신뢰를 잃음 | 중간 |

## 2. 들어올 수 있는 길

| 길 | 로그인 | 지금 막아 둔 것 |
|---|---|---|
| `/api/subscribe` | 없음 | 속도 제한(IP·메일 해시), 확인 메일 없이는 구독 안 됨 |
| `/api/community` | 없음(글은 메일 확인) | 속도 제한, 확인 토큰 30분, 원문 붙여넣기 차단 |
| `/api/admin*` | 있음 | scrypt 해시, 12시간 세션, 5회 실패 15분 잠금 |
| `/api/weekly` | 크론 비밀 또는 관리 키 | `CRON_SECRET` 대조 · **전수 수집 스위치 꺼짐** |
| 정적 페이지 1,951장 | 없음 | 읽기 전용 |
| Cloudflare 워커 4개 | 없음 | 외부 공개 데이터만 중계 |

## 3. 생각해 둔 공격과 대응

**가. 메일 폭탄 / 스팸 발판**
누군가 남의 주소를 넣고 구독 신청을 반복하면, 우리 계정에서 메일이 나갑니다.
→ 속도 제한(같은 IP 15분 5회, 메일별 제한), 확인 링크 전에는 아무것도 보내지 않음.
→ **남은 위험**: 분산된 IP 로 들어오면 전체 한도만 남습니다. 발신 계정의 일일 한도가 마지막 방어선입니다.

**나. 관리자 비밀번호 추측**
→ 15분 5회 잠금 + 전체 30회 잠금. 비밀번호는 scrypt 해시.
→ 2026-11-20부터 **들어온 기록이 남습니다** — 성공·실패·잠금·비밀번호 변경. 「내가 안 한 로그인」을 볼 수 있습니다.
→ **남은 위험**: 2단계 인증이 없습니다. 비밀번호가 새면 그대로 들어옵니다. 기록은 사후에 알게 해 줄 뿐 막지는 못합니다.

**다. 토큰·키 유출**
`BLOB_READ_WRITE_TOKEN` 하나로 구독자·커뮤니티 자료 전체에 닿습니다.
→ 소스에 두지 않음, 배포 폴더 검사 자동화(`smoke-privacy.mjs`).
→ **남은 위험**: 유출 시 범위가 넓습니다. 토큰 교체 절차를 적어 둘 것.

**라. 공공 API 키 도용**
키는 서버·`.secrets/` 에만 있고 브라우저로 나가지 않습니다.
→ 실거래 조회는 **내 PC 스크립트**와 워커에서만 합니다. 화면 코드에 키가 없습니다.

**마. 남의 자료를 우리가 퍼뜨리는 것**
이것이 2026-11 에 실제로 일어난 일입니다 — KB 평당가 집계가 공개 URL 로 두 달 열려 있었습니다.
→ `smoke-no-unlicensed.mjs` 가 배포될 파일을 직접 열어 확인합니다.

**바. 추정가를 실거래가로 오해**
법적 문제이자 신뢰 문제입니다. 「24억」이라고만 적으면 그 값에 팔 수 있다는 뜻으로 읽힙니다.
→ 추정치·범위·건수·등급·기준월·출처를 **한 화면에 함께** 적고, 테스트로 고정(`smoke-pages.mjs`).

**사. 글을 지워 달라는 요청**
→ 지금은 메일로만 받습니다. 받으면 지웁니다. 화면에서 바로 지우는 길은 아직 없습니다.

## 4. 일부러 하지 않는 것

- **개인 식별 추적** — 방문 집계에 IP·User-Agent 를 담지 않습니다. 한 사람이 몇 번 왔는지 알 수 없고, 그렇게 두었습니다.
- **비밀번호 저장** — 원문을 어디에도 두지 않습니다.
- **제3자 분석 도구** — 외부 스크립트를 넣지 않습니다(방문 집계는 자체 코드 10줄).

## 5. 결제를 받기 전에 반드시 할 것 (P4 진입 조건)

1. 결제 정보는 **우리 서버에 저장하지 않는** 구조(PG 위임) 확정
2. 관리자 2단계 인증
3. 관리자 접근 기록(로그인 시각·결과)
4. 환불·분쟁 처리 절차와 책임 범위 고지
5. 개인정보 파기 요청을 화면에서 받는 길
6. 배포 전 `npm audit` 자동 실행
